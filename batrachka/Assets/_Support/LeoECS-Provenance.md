# LeoECS Proto

В проект включён оригинальный пакет **LeoECS Proto Core 2025.11.4**.

- Официальный источник: https://gitverse.ru/leopotam/ecsproto
- Git: https://gitverse.ru/leopotam/ecsproto.git
- Commit: `f4ce0e9300446547ce8e213318909fcecddc867b`
- Установка: исходный пакет в `Packages/ru.leopotam.ecsproto`, локальная UPM-зависимость в `Packages/manifest.json`.
- Исходники пакета не изменены. Сохранены README, asmdef, package.json, метаданные и лицензия MIT-ZARYA.
- Копирование официальных исходников предусмотрено разделом «Установка / В виде исходников» README библиотеки. Локальный пакет позволяет открыть проект без повторной загрузки Git-зависимости.
- Минимальная Unity из package.json: 2021.3; проект использует 2022.3.9f1.
- В текущем прототипе нет текстового интерфейса. Копия лицензии включается в WebGL-сборку.

Документация Unity о встроенных пакетах: https://docs.unity3d.com/2022.3/Documentation/Manual/upm-embed.html
