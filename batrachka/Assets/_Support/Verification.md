# Проверка минимальной версии

12 ноября 2026, Unity 2022.3.9f1, LeoECS Proto 2025.11.4.

Проверка выполнена пакетным запуском Unity в основном проекте после изменения сцены и структуры кода.

- **16 EditMode-тестов пройдено:** выделение, движение, замена приказов, независимость невыбранных юнитов, поворот, отмена предыдущего направления обычным приказом, уникальные позиции и границы повёрнутого построения.
- **2 PlayMode-теста пройдено:** сохранённая сцена создаёт 60 солдат; raycast по Capsule, обратная рамка, удержание/отпускание ПКМ, отмена жеста и потеря фокуса, сохранение точки назначения при перетаскивании, прибытие и конечное направление.
- В сцене проверены **61 MeshRenderer** (Plane + 60 Capsule), **0 Canvas**, изометрическая камера 35.26439° / 45° и английские имена всех объектов.
- Каждый C#-файл приложения находится в `Assets/_Source/<namespace>`; namespace совпадает с именем содержащей папки. Официальный пакет LeoECS не изменён.
- Изображение минимальной сцены получено через рендер камеры в PlayMode и визуально проверено.
- WebGL / IL2CPP успешно собран: около **4.6 MB** по отчёту Unity. В браузере через локальный HTTP проверены загрузка, одиночное и рамочное выделение, движение и прибытие группы. Ошибок и предупреждений в консоли не обнаружено. Жест задания направления проверен интеграционными PlayMode-тестами.

## Файлы проверки

- `Logs/RtsMinimalGenerate.log` — пересоздание сцены.
- `Logs/RtsMinimalEditMode.xml` и `.log` — результаты EditMode.
- `Logs/RtsMinimalPlayMode.xml` и `.log` — результаты PlayMode.
- `Logs/RtsMinimalPreview.png` — рендер сцены после движения и поворота.
- `Logs/RtsMinimalWebGL.log` — журнал актуальной WebGL-сборки.
- `Logs/RtsMinimalWebGLPreview.jpg` — снимок актуальной сборки в браузере.

При первом запуске после переноса файлов Unity обновила старый кэш компиляции. Последующие тестовые запуски выполнялись с новой структурой и прошли без ошибок компиляции.

Для запуска открыть `Assets/_Presentation/Scenes/RtsTraining.unity` и нажать Play. Объекты и ссылки уже подготовлены. Коммиты, push и публикация не выполнялись.
