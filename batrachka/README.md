# ECS Практика

Unity 2022.3.9f1, LeoECS Proto 2025.11.4. Учебная механика управления группой: обычный Plane, 60 Capsule, изометрическая камера. Без HUD, надписей и декораций.

## Запуск

Открыть `Assets/_Presentation/Scenes/RtsTraining.unity` и нажать **Play**. Ссылки назначены, капсулы создаются автоматически из `Soldier.prefab`.

**ECS Practice → Rebuild Demo Scene** пересоздаёт сцену, префаб и простые материалы. Все объекты сцены названы на английском.

## Управление

- ЛКМ — выбрать одну капсулу; удерживать и тянуть ЛКМ — выделить рамкой.
- Shift + ЛКМ/рамка — добавить к выделению; A — выбрать всех; Esc — снять выделение и отменить текущий жест.
- Клик ПКМ по Plane — движение к точке, приказ применяется при отпускании кнопки.
- Зажать ПКМ в точке назначения, потянуть мышь в нужную сторону и отпустить — движение в построении с указанным конечным направлением взгляда.
- Точка назначения фиксируется при нажатии ПКМ. Во время удержания новый приказ ещё не применяется. Направление можно менять до отпускания.
- Во время движения капсулы смотрят по ходу движения, после прибытия плавно поворачиваются в заданную сторону. Обычный новый клик ПКМ сбрасывает старый приказ поворота.
- Потеря фокуса, Esc и отпускание ПКМ вне окна отменяют неподтверждённый приказ.

Выделенные капсулы зелёные. Короткая линия перед выбранной капсулой показывает её направление — у симметричной Capsule иначе не видно вращения. Рамка и стрелка при удержании ПКМ рисуются через LineRenderer в мире; Canvas и UI отсутствуют.

## Код

Каждому namespace соответствует одноимённая папка в `Assets/_Source`:

| Папка / namespace | Назначение |
| --- | --- |
| `CoreSystem` | Bootstrap, ProtoWorld, аспект, время и состояние для проверки |
| `PlayerSystem` | Ввод мыши, команды, система выделения |
| `UnitSystem` | ECS-компоненты, построение, движение и поворот |
| `ViewSystem` | Отображение ECS, подсветка, функциональные линии и камера |
| `EditorSystem` | Создание сцены и WebGL-сборка |
| `EditModeTestsSystem` | Тесты ECS и построения |
| `PlayModeTestsSystem` | Проверка сцены и ввода |

Порядок выполнения: **ввод → выделение → приказ → движение → поворот → отображение**.

Позиция, цель, выделение, текущий поворот и требуемое направление хранятся в LeoECS Proto. `MovementSystem` и `RotationSystem` изменяют ECS-компоненты; `UnitViewSystem` копирует результат в Transform. На капсулах нет `Update`.

Официальная библиотека сохранена без изменений в `Packages/ru.leopotam.ecsproto`; исходный namespace библиотеки оставлен как есть. Происхождение и версия: `Assets/_Support/LeoECS-Provenance.md`.

Плоскость свободна от препятствий. Поиска пути и столкновений между капсулами нет; цели в построении уникальны и не выходят за границы Plane даже при повороте построения.

## Проверка и WebGL

**Window → General → Test Runner** — EditMode и PlayMode.

**ECS Practice → Build WebGL for GitHub Pages** — сборка в `Builds/WebGL` (нужен WebGL Build Support для Unity 2022.3.9f1). Настроены IL2CPP, Gzip с decompression fallback и `.nojekyll`. ПКМ на canvas не открывает контекстное меню браузера.

Для локального просмотра через HTTP, из корня проекта:

```powershell
node Assets/_Support/serve-webgl.cjs
```

Открыть http://127.0.0.1:8000. Остановить сервер: Ctrl+C.

Для будущей публикации перенести всё содержимое `Builds/WebGL` в источник GitHub Pages. Коммиты, push и публикация автоматически не выполняются. Результаты проверки: `Assets/_Support/Verification.md`.
